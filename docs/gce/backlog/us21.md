## História de Usuário

Como equipe de desenvolvimento, quero hospedar o sistema (frontend, API, banco de
dados e arquivos) em serviços de nuvem gratuitos para que ele fique disponível
online sem depender da máquina de um membro do grupo.

## Tarefas

- Criar o banco PostgreSQL no Neon e aplicar as migrações do Alembic;
- Migrar os dados do banco de produção atual para o Neon;
- Publicar a API no Render a partir do Dockerfile do backend;
- Publicar o frontend no Netlify apontando para a URL da API no Render;
- Configurar as variáveis de ambiente (secrets) no Render e no Netlify;
- Configurar o CORS da API para o domínio do Netlify;
- Substituir o serviço de scheduler por um workflow agendado do GitHub Actions que chama um endpoint protegido da API;
- Armazenar os documentos no Google Drive ([US09](./us09.md)), já que o disco do Render é temporário;
- Configurar o deploy automático do frontend e da API a partir da branch `main`;
- Atualizar a documentação de deploy.

## Critérios de Aceitação

- O frontend deve estar acessível publicamente por HTTPS no Netlify;
- A API deve estar acessível por HTTPS no Render e responder em `/api/v1/health`;
- O banco de dados no Neon deve aceitar apenas conexões autenticadas e com SSL;
- As notificações de vencimento devem continuar sendo enviadas nos horários previstos;
- Os documentos anexados não devem ser perdidos após reinício ou novo deploy da API;
- Nenhum dos serviços utilizados deve gerar custo;
- O sistema não deve depender da máquina de nenhum membro do grupo;
- As credenciais de administrador devem permitir o acesso ao painel.

## Observações

- A [US20](./us20.md) fez o deploy em uma máquina de um membro do grupo. Esta história
  move o sistema para serviços de nuvem gratuitos, por pedido do professor.
- No plano gratuito do Render, a API hiberna após cerca de 15 minutos sem acesso, e a
  primeira requisição seguinte pode levar até 1 minuto.
- O plano gratuito do Render não oferece workers em segundo plano nem disco persistente,
  por isso o agendamento passa para o GitHub Actions e os documentos para o Google Drive.
- Os limites dos planos gratuitos devem ser conferidos na hora da configuração.
