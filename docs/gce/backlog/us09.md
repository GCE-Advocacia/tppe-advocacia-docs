## História de Usuário

Como membro da equipe, quero que os documentos anexados aos processos sejam
armazenados no Google Drive do escritório para acessá-los também pelo Drive,
organizados por processo.

## Tarefas

- Definir com o cliente a conta do Drive utilizada (Google Workspace ou conta Gmail do escritório);
- Configurar a conta do escritório para o sistema (conta de serviço com Drive compartilhado ou conexão OAuth feita pelo administrador);
- Implementar o armazenamento de documentos no Google Drive;
- Criar automaticamente uma pasta para cada processo no Drive;
- Permitir o download dos documentos armazenados no Drive pelo sistema;
- Permitir escolher entre armazenamento local e Google Drive por configuração;
- Registrar falhas de comunicação com o Google Drive nos logs de integração;
- Notificar os administradores em caso de falha na integração.

## Critérios de Aceitação

- Os documentos enviados pelo sistema devem ser armazenados no Google Drive do escritório;
- Cada documento deve ficar na pasta do processo ao qual foi anexado;
- Os documentos devem continuar sendo listados e baixados pela página do processo;
- O acesso aos documentos pelo sistema deve continuar respeitando as permissões do usuário;
- Os documentos não devem ser compartilhados por link público;
- Em caso de falha do Google Drive, o usuário deve receber uma mensagem de erro e a falha deve ser registrada;
- O sistema deve continuar funcionando com armazenamento local quando a integração estiver desativada.

## Observações

- A [US04](./us04.md) entrega a gestão de documentos com armazenamento local. Esta história
  troca apenas o local de armazenamento, mantendo no banco de dados a associação dos
  documentos aos processos e as permissões de acesso.
- O acesso ao Drive deve usar o escopo `drive.file`, que limita o sistema aos arquivos
  criados por ele.
- Anexar arquivos já existentes no Drive (Google Picker) não faz parte desta história.
