## História de Usuário

Como membro da equipe, quero anexar documentos aos processos cadastrados para
centralizar os arquivos relacionados a cada processo.

## Tarefas

- Criar estrutura de documentos no banco de dados;
- Associar documentos aos processos;
- Implementar upload de arquivos;
- Validar formato dos arquivos;
- Validar tamanho dos arquivos;
- Listar documentos de um processo;
- Permitir acesso aos documentos;
- Implementar permissões de acesso.

## Critérios de Aceitação

- O usuário deve conseguir anexar um documento a um processo;
- O documento deve permanecer associado ao processo correto;
- Os documentos devem aparecer na página do processo;
- O sistema deve validar os tipos de arquivos permitidos;
- O sistema deve respeitar as permissões do usuário.
