## História de Usuário

Como administrador, quero visualizar entradas e saídas financeiras para acompanhar
o faturamento do escritório.

## Tarefas

- Criar estrutura financeira no banco de dados;
- Permitir cadastro de entradas;
- Permitir cadastro de saídas;
- Criar página de controle financeiro;
- Criar filtros por período;
- Calcular total de entradas;
- Calcular total de saídas;
- Calcular saldo;
- Exibir resumo financeiro.

## Critérios de Aceitação

- Deve ser possível cadastrar uma entrada;
- Deve ser possível cadastrar uma saída;
- Deve ser possível consultar registros financeiros por período;
- O sistema deve exibir o total de entradas;
- O sistema deve exibir o total de saídas;
- O sistema deve calcular o saldo corretamente.
