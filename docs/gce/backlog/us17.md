## História de Usuário

Como administrador do sistema, quero alternar a visualização da prévia entre formatos Desktop,
Tablet e Mobile para a Landing Page e alternar para a prévia do Painel do Sistema na aba de
Identidade Visual, para conferir como a identidade visual, o contraste e a legibilidade se comportam
tanto em smartphones quanto no painel administrativo dos advogados antes de salvar.

## Tarefas

- Desenvolver barra superior no componente `LandingPreview.tsx` com alternadores de visão entre "Landing Page" e "Painel do Sistema";
- Adicionar botões de *viewport* responsivo para a Landing Page: Desktop, Tablet e Mobile;
- Criar moldura simulada de smartphone (`375px`) com cantos arredondados, sombra de aparelho e altura fixa de *viewport* (`~640px`) com rolagem interna suave;
- Criar moldura de tablet (`768px`) centralizada com bordas suaves;
- Adicionar classes CSS responsivas para reorganizar o conteúdo mobile em coluna única vertical sem *overflow* horizontal;
- Desenvolver simulador do Painel do Sistema (mini-dashboard com Sidebar, títulos de módulo, cartões de métricas e botão de ação consumindo `--brand-accent` e `--btn-radius`);
- Integrar com o modo de inspeção direta no preview ([US18](https://github.com/GCE-Advocacia/.github/issues/21)) para funcionar em qualquer dispositivo ativo.

## Critérios de Aceitação

- A barra do preview deve permitir alternar em 1 clique entre "Landing Page" e "Painel do Sistema";
- Na Landing Page, deve ser possível alternar entre Desktop (`100%`), Tablet (`768px`) e Mobile (`375px`) instantaneamente;
- No modo Mobile, a prévia deve exibir moldura de smartphone com rolagem interna suave sem quebra horizontal;
- No Painel do Sistema, a Sidebar e os botões devem refletir as cores e o `border-radius` ativos em tempo real;
- Alternar entre os modos de preview deve preservar todos os dados e rascunhos em edição.

## Observações
