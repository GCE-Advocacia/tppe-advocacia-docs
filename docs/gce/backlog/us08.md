## História de Usuário

Como administrador, quero alterar a logo da Landing Page pela área administrativa
para personalizar a identidade visual do site.

## Tarefas

- Criar campo para upload da logo;
- Validar formato do arquivo;
- Validar tamanho do arquivo;
- Salvar a nova logo;
- Atualizar a Landing Page;
- Permitir substituição da logo existente.

## Critérios de Aceitação

- Apenas administradores devem poder alterar a logo;
- Deve ser possível fazer upload de uma nova logo;
- A nova logo deve aparecer na Landing Page;
- A configuração deve permanecer salva.
