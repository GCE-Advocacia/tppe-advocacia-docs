## História de Usuário

Como administrador, quero selecionar temas pré-definidos e criar/salvar novos temas para personalizar a Landing Page.

## Tarefas

 - Criar estrutura de temas no banco de dados;
 - Disponibilizar temas pré-definidos;
 - Permitir salvar novos temas respeitando um limite máximo de temas no total (x padrão e até y personalizados);
 - Permitir alterar temas existentes.

## Critérios de Aceitação

 - O sistema possui temas pré-definidos;
 - É possível criar até novos temas respeitando o limite máximo;
 - É possível editar temas existentes;
 - Apenas administradores podem gerenciar os temas.
