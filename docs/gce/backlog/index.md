# Backlog do Produto — GCE

Esta página reúne os requisitos do projeto de advocacia na disciplina de GCE, dando
continuidade ao sistema desenvolvido em TPPE. O backlog herdado da etapa anterior
continua disponível em [Backlog (TPPE)](../../backlog/index.md).

Cada história de usuário tem uma página própria, listada abaixo e também no menu
lateral, com a descrição completa, os responsáveis e o status atual.

O trabalho está dividido entre quatro subgrupos, listados na seção
[Subgrupos](#subgrupos). A atribuição dos requisitos a cada subgrupo é feita no
planejamento de cada sprint, e fica registrada na página da sprint correspondente.
