## História de Usuário

Como administrador, quero alterar as cores da Landing Page para personalizar a
identidade visual do sistema.

## Tarefas

- Definir quais cores podem ser personalizadas;
- Criar seletor de cores;
- Salvar configurações no sistema;
- Aplicar cores dinamicamente na Landing Page;
- Criar opção de restauração das cores padrão.

## Critérios de Aceitação

- Apenas administradores devem poder alterar as cores;
- As cores escolhidas devem ser salvas;
- As alterações devem aparecer na Landing Page;
- As configurações devem permanecer após reiniciar o sistema.
