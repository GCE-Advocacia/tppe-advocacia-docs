## História de Usuário

Como administrador, quero permitir ou negar a visualização de vencimentos para cada
funcionário para controlar quem acompanha os pagamentos dos clientes.

## Tarefas

- Criar estrutura de permissão no banco de dados;
- Restringir a visualização de vencimentos conforme a permissão do usuário;
- Manter cadastro, edição e exclusão de vencimentos restritos ao administrador;
- Permitir conceder e revogar a permissão na tela de usuários;
- Exibir a página de pagamentos em modo somente leitura para o funcionário;
- Ocultar o menu e bloquear a rota de pagamentos para quem não tem permissão.

## Critérios de Aceitação

- Apenas administradores e funcionários autorizados devem poder visualizar os vencimentos;
- Apenas administradores devem poder cadastrar, alterar ou excluir vencimentos;
- O administrador deve conseguir conceder e revogar a permissão de cada funcionário;
- A revogação da permissão deve valer imediatamente;
- O sistema deve respeitar as permissões do usuário.

## Observações

- Os vencimentos são os pagamentos cadastrados no calendário da [US01](./us01.md).
- A permissão é individual, guardada no campo `can_view_payments` do usuário, e vale apenas
  para o funcionário (`USER`). Administradores sempre visualizam os vencimentos.
- Uma permissão concedida aparece no menu a partir do próximo login do funcionário. A
  revogação bloqueia o acesso imediatamente.
