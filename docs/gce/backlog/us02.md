## História de Usuário

Como administrador, quero que o sistema envie lembretes de pagamento aos clientes
para reduzir atrasos.

## Tarefas

- Identificar pagamentos próximos ao vencimento;
- Implementar envio de e-mail;
- Enviar e-mail um dia antes do vencimento;
- Enviar e-mail no dia do vencimento;
- Evitar envio duplicado de notificações;
- Registrar notificações enviadas;
- Criar testes para o envio de e-mails.

## Critérios de Aceitação

- O cliente deve receber um e-mail um dia antes do vencimento;
- O cliente deve receber um e-mail no dia do vencimento;
- O sistema não deve enviar a mesma notificação mais de uma vez;
- O envio deve utilizar o e-mail cadastrado do cliente.
