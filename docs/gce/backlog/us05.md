## História de Usuário

Como advogado, quero adicionar tarefas específicas dentro de um processo e atribui-las aos membros da equipe, para mapear e documentar as etapas do que precisa ser feito no escritório.

## Tarefas

- [x] criar a seção "Tarefas" na ficha do processo
- [x] colocar o botão "Nova tarefa"
- [x] abrir o formulário de tarefa a partir do processo
- [x] escolher o responsável ao criar a tarefa
- [x] mostrar a lista de tarefas do processo dentro da ficha dele
- [x] já vincular a tarefa ao processo quando criar por ali
- [x] mostrar o responsável e o prazo de cada tarefa na lista
- [x] permitir clicar numa tarefa da lista para editar
- [x] permitir trocar o responsável da tarefa por ali mesmo
- [x] atualizar a lista sozinha depois de criar ou editar uma tarefa
- [x] avisar quando o processo ainda não tem nenhuma tarefa
- [x] permitir apagar tarefas na ficha do processo

## Critérios de Aceitação

- [x] Criar tarefa pela ficha do processo: Dado que estou na ficha de um processo, quando clico em "Nova tarefa" na seção Tarefas, então o formulário abre em modal com o campo "Processo" já preenchido e bloqueado, e a tarefa salva fica vinculada àquele processo.
- [x] Atribuir responsável: Ao criar a tarefa, posso escolher o responsável entre os usuários ativos do escritório ou deixá-la sem responsável.
- [x] Lista de tarefas na ficha: A seção Tarefas exibe apenas as tarefas daquele processo, cada uma com título, status, responsável (ou "Sem responsável") e prazo.
- [x] Editar e trocar o responsável: Quando clico em uma tarefa da lista, o formulário abre preenchido em modo edição e posso alterar seus dados, inclusive o responsável, sem sair da ficha do processo.
- [x] Excluir tarefa: Quando clico no ícone de excluir em uma tarefa, o sistema pede confirmação antes de apagar; ao confirmar, a tarefa é removida do processo e do quadro de tarefas; se a exclusão falhar, a tarefa permanece e a mensagem de erro é exibida.
- [x] Lista sempre atualizada: Depois de criar, editar ou excluir uma tarefa, a lista da ficha reflete a mudança imediatamente, sem recarregar a página; se não restar nenhuma tarefa, é exibida a mensagem "Nenhuma tarefa cadastrada neste processo."
