## História de Usuário

Como administrador, quero alterar as imagens da Landing Page pela área administrativa
para personalizar o site sem modificar diretamente o código.

## Tarefas

- Criar configuração de imagens da Landing Page;
- Criar campo de upload na área administrativa;
- Validar formato da imagem;
- Validar tamanho da imagem;
- Salvar a imagem;
- Atualizar a Landing Page automaticamente.

## Critérios de Aceitação

- Apenas usuários administradores devem poder alterar as imagens;
- Deve ser possível realizar upload de uma nova imagem;
- A imagem alterada deve aparecer na Landing Page;
- A alteração deve permanecer salva após reiniciar o sistema.
