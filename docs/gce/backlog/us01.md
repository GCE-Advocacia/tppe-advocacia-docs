## História de Usuário

Como administrador, quero cadastrar e visualizar os dias de pagamento dos clientes
para acompanhar os vencimentos.

## Tarefas

- Criar estrutura de pagamentos no banco de dados;
- Associar pagamentos aos clientes;
- Permitir cadastrar data de vencimento;
- Permitir editar a data de vencimento;
- Criar visualização em formato de calendário;
- Exibir pagamentos por data;
- Exibir status do pagamento;
- Diferenciar pagamentos pagos e pendentes.

## Critérios de Aceitação

- O administrador deve conseguir cadastrar um vencimento;
- O vencimento deve estar associado a um cliente;
- O pagamento deve aparecer no calendário;
- Deve ser possível identificar se o pagamento está pago ou pendente;
- Deve ser possível alterar a data de vencimento.
